# NOTICE — Attributions

OpcOS is an original framework, but several of its ideas were distilled from — or
inspired by — prior open-source work. Thank you to these projects:

- **[everything-claude-code](https://github.com/affaan-m/everything-claude-code)** (MIT, affaan-m) — origin of the config garbage-collection concept and several security-review / orchestration patterns adapted into this framework.
- **[ponytail](https://github.com/DietrichGebert/ponytail)** (MIT, Dietrich Gebert) — the "write-code-last" decision ladder distilled into the core governance template.
- **[agents.md](https://agents.md)** (agentsmd) — the AGENTS.md open standard that the governance template's structure follows for cross-tool portability.
- **[rulesync](https://github.com/dyoshikawa/rulesync)** (MIT, dyoshikawa) — inspiration for the data-driven adapter-table pattern used to deploy one rule source to many tools.

No source code from these projects is redistributed in this repository unless
explicitly marked; attributions above cover concepts and patterns. See each
project's own LICENSE for its terms.
